## Quando usar
Use esta skill para telas, layouts, fluxos visuais e integracoes frontend depois do handoff do product-owner.

## Pre-condicao
Confirme que existem problema, escopo MVP e criterios de aceite. Se nao existirem, volte ao product-owner.

## Regras
- Use Next.js como default de frontend.
- Use shadcn/ui como base de componentes quando a implementacao for aprovada.
- Mantenha a UI simples, responsiva e acessivel.
- Crie componentes somente para o escopo aprovado.
- Evite estado global e abstracoes sem necessidade.

## Saida esperada
- Telas ou rotas afetadas.
- Componentes necessarios.
- Dados necessarios.
- Criterios de aceite atendidos.
- Dependencias de backend ou data.

Create a new file `agents/app/auth.py` with exactly the following content:

```python
from __future__ import annotations

from fastapi import HTTPException, Security
from fastapi.security import APIKeyHeader
from starlette.status import HTTP_403_FORBIDDEN

from app.settings import settings

_api_key_header = APIKeyHeader(name="X-API-Key", auto_error=False)


async def verify_api_key(api_key: str | None = Security(_api_key_header)) -> str:
    """Validate X-API-Key header against BACKEND_BEARER_TOKEN.

    Returns the api_key string on success.
    Raises HTTP 403 if the header is missing or the value does not match.
    """
    if not api_key or api_key != settings.backend_bearer_token:
        raise HTTPException(
            status_code=HTTP_403_FORBIDDEN,
            detail="Invalid or missing API key",
        )
    return api_key
```

Key implementation notes:
- `auto_error=False` on APIKeyHeader: FastAPI will NOT auto-respond 403; we control the error message manually in the function body — this gives us a consistent detail message
- `Security(_api_key_header)` (not `Depends`): FastAPI's `Security()` is the correct wrapper for `APIKeyHeader` to enable OpenAPI docs integration
- The comparison `api_key != settings.backend_bearer_token` is safe because plan 02-02 guarantees `settings.backend_bearer_token` is a non-empty `str` at startup — never `None`

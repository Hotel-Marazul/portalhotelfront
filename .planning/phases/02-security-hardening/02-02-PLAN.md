<objective>
Add mandatory startup validation to the agents service so it refuses to start if `BACKEND_BEARER_TOKEN` is absent or empty (SEC-04).

Purpose: Currently `settings.backend_bearer_token` is `str | None` and `load_settings()` silently returns `None` when the env var is missing. This allows the service to start and serve requests with no authentication token configured. Adding a `RuntimeError` guard at `load_settings()` time causes uvicorn to crash before binding a port, with a clear error message in container logs.

Output: Modified `agents/app/settings.py` with startup guard and `str` type annotation on `backend_bearer_token`.
</objective>

      return Settings(

Why RuntimeError propagates: `settings = load_settings()` is module-level in settings.py.
When Python imports `app.settings`, the RuntimeError is raised during module loading.
FastAPI/uvicorn cannot import the app module → process exits with non-zero code.
This is the correct behavior: fail fast, fail loudly, fail before accepting traffic.

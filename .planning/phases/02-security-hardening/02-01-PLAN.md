## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-02-01 | Spoofing | POST /User/login | mitigate | express-rate-limit 10 req/15min per IP — already applied in auth.routes.ts (SEC-01 verified) |
| T-02-02 | Information Disclosure | docker-compose.yaml default credentials | mitigate | Replace ${VAR} with ${VAR:?error} so missing credentials fail loudly at compose startup (SEC-03) |
| T-02-03 | Elevation of Privilege | DB running with admin/admin from .env | mitigate | :? interpolation + .env.compose.example documents requirement; local .env must be set explicitly |
</threat_model>

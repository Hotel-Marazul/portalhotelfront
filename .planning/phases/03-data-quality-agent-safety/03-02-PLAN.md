<objective>
Insert a human-confirmation gate in the AI agent's booking flow. Before any DB write, the agent must stash the booking payload in conversation context, reply with a summary and "Confirmar reserva?", and only proceed to create the reservation when the user replies with an explicit confirmation word.

Purpose: Prevents accidental bookings — users control when the AI commits to the database. This is QUA-02: "Usuário confirma detalhes antes do agente IA criar reserva no banco."

Output: Two files modified. `supervisor.py` gets a pre-routing pending-booking check. `flows.py` gets `_is_confirmation()` and a gate at the top of `run_booking()`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user→agent (/chat POST) | User message is untrusted; "sim" or any text arrives here |
| agent→backend API | booking_agent.create() calls POST /Reservations — DB write boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-02-01 | Spoofing | supervisor.py pending_booking check | mitigate | Confirmation only triggers when `pending_booking` exists in the conversation's own context dict (per-conversation-id); cross-conversation spoofing is impossible with the current in-memory store |
| T-03-02-02 | Tampering | flows.py run_booking gate | mitigate | `confirmed=True` is only set by supervisor after explicit `_is_confirmation()` check; cannot be set by the user directly (it is a Python keyword arg, not a JSON field) |
| T-03-02-03 | Denial of Service | stale pending_booking | accept | In-process memory; a stale pending booking is cleared on any non-confirmation message. No persistent DoS risk. V2 concern if sessions become DB-backed. |
| T-03-02-04 | Information Disclosure | confirmation reply summary | accept | Summary contains room_id, dates, client_id — all data the user themselves provided in the same conversation. No new information disclosed. |
</threat_model>

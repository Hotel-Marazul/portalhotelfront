# Formato de documentos para RAG

Cada documento em `rag/knowledge/` deve:

1. Ser `.md` ou `.txt`.
2. Ter título claro no início.
3. Explicar política em linguagem objetiva.
4. Opcionalmente conter metadados:

```md
---
source: manual-interno
topic: cancelamento
updated_at: 2026-03-03
---
```

## Boas práticas

- Um tema por arquivo.
- Evitar duplicidade de política.
- Atualizar documento ao mudar regra operacional.
